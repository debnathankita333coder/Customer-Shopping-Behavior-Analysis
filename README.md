# Customer-Shopping-Behavior-Analysis
End-to-end customer shopping behavior data analysis project showcasing data cleaning, preprocessing, relational database storage, exploratory SQL querying, and interactive executive dashboard design.

## 🚀 Project Overview
This project analyzes customer shopping transactions to uncover revenue trends, regional performance, and top-performing products. The pipeline moves raw data from initial ingestion and cleaning in Python to structured storage in MySQL, followed by deep-dive analytical querying and visualization in Power BI.

---

## 🛠️ Tech Stack & Tools
* *Python (Pandas, SQLAlchemy, PyMySQL):* Data cleaning, missing value handling, duplicate removal, and automated database ingestion.
* *MySQL & MySQL Workbench:* Relational database storage (salesdb) and analytical business querying.
* *Power BI:* Interactive dashboard creation for visual storytelling and KPI tracking.
* *Git & GitHub:* Version control and project portfolio hosting.
